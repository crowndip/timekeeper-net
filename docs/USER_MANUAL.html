📖 Overview

The Parental Control System is a centralized solution for managing computer time across multiple devices. It consists of three main components:

Key Features

  • Centralized Management: Control all devices from one web dashboard
  • Cross-Platform: Works on Linux and Windows
  • Shared Time Limits: Time is tracked across all devices
  • Multi-Language: Supports English, Czech, German, French, and Spanish
  • Real-Time Enforcement: Automatic logout/lock when time expires
  • Offline Mode: Continues working even without server connection
💡 How It Works: The server stores all time limits and usage data. Clients check in every minute to report usage and get remaining time. When time runs out, the client automatically logs out the user.

🖥️ Server Setup

Prerequisites

  • Docker and Docker Compose installed
  • 2GB RAM minimum
  • 10GB disk space
  • Network access from client devices

Installation Steps

  1. Download docker-compose.yml

    wget https://raw.githubusercontent.com/crowndip/timekeeper-net/main/docker-compose.yml

  2. Set Environment Variables

    export ADMIN_PASSWORD=your_dashboard_password
export LIMIT_ADMIN_PASSWORD=your_admin_operations_password
export DB_PASSWORD=your_database_password
    ⚠️ Important: Change these passwords! The default ADMIN_PASSWORD is "admin" which is insecure.

  3. Start the Server

    docker-compose up -d

    This will start two containers:

    • webservice: The main application (port 8080)
    • postgres: The database (port 5432, internal only)

  4. Verify Installation

    Open your browser and navigate to:

    http://your-server-ip:8080

    You should see the dashboard login page.

✅ Server is Ready! You can now access the dashboard and configure users and time limits.

📊 Web Dashboard

Accessing the Dashboard

Navigate to http://your-server-ip:8080 in your web browser.

🔒 Authentication: The dashboard requires a password. Default is "admin" but you should change this via the ADMIN_PASSWORD environment variable.

Dashboard Overview

Managing Users

Click on Users to manage user accounts:

Action Description
Add User Create a new user account manually (users are also auto-created on first login)
Edit User Change username, full name, email, account type (Parent/Child/Unassigned)
⏱️ Time Button Grant emergency time (+5, +15, +30, +60 minutes) for today only
👥 Aliases Link multiple usernames to the same account (e.g., "john" and "John")
Delete User Remove user account (cannot be undone)
💡 Account Types:
  • Parent: No time limits, unrestricted access
  • Child: Subject to time limits and restrictions
  • Unassigned: Needs configuration (default for auto-created users)

Setting Time Limits

Click on Time Profiles to configure time limits:

  1. Click "+ Add Profile"

    Create a new time profile for a user

  2. Select User

    Choose which user this profile applies to

  3. Set Daily Limits

    Enter time limits in minutes for each day of the week:

    • Monday through Sunday
    • 0 = No access
    • Leave empty = Unlimited
    • Example: 120 = 2 hours

  4. Set Weekly Limit (Optional)

    Total minutes allowed per week across all days

  5. Save Profile

    Profile becomes active immediately

⚠️ Time Limits: Both daily AND weekly limits are enforced. If either limit is reached, access is blocked.

Configuring Allowed Hours

Click on Allowed Hours to set when users can access computers:

Example: Allow computer use only from 3:00 PM to 8:00 PM on weekdays

  1. Click "+ Add Schedule"
  2. Select user
  3. Select day (Monday-Sunday)
  4. Set start time (e.g., 15:00)
  5. Set end time (e.g., 20:00)
  6. Save
💡 Tip: You can create multiple schedules for the same user on different days. For example, different hours for weekdays vs. weekends.

Language Selection

The dashboard supports 5 languages:

  • 🇬🇧 English
  • 🇨🇿 Čeština (Czech)
  • 🇩🇪 Deutsch (German)
  • 🇫🇷 Français (French)
  • 🇪🇸 Español (Spanish)

The language is automatically detected from your browser, but you can change it using the dropdown in the top-right corner.

💻 Client Setup

Linux Client Installation

Option 1: Automatic Installation (Recommended)

One-line installation script:

curl -fsSL https://raw.githubusercontent.com/crowndip/timekeeper-net/main/scripts/install-linux-client.sh | sudo bash -s -- http://your-server-ip:8080

Or interactive mode (prompts for server URL):

curl -fsSL https://raw.githubusercontent.com/crowndip/timekeeper-net/main/scripts/install-linux-client.sh | sudo bash
✅ What the script does:
  • Downloads latest client release
  • Installs to /opt/parental-control
  • Configures systemd service
  • Starts service automatically

Option 2: Ubuntu/Debian Package

# Download .deb package
wget https://github.com/crowndip/timekeeper-net/releases/latest/download/parental-control-client_amd64.deb

# Install
sudo dpkg -i parental-control-client_*.deb

# Configure server URL
sudo nano /opt/parental-control/appsettings.json

# Start service
sudo systemctl start parental-control-client

Windows Client Installation

  1. Download Windows Client

    Download client-windows-x64.zip from GitHub Releases

  2. Extract Files

    Extract to a temporary folder (e.g., C:\Temp\parental-control)

  3. Run Installer

    Open PowerShell as Administrator and run:

    .\install-windows-client.ps1 -ServerUrl "http://your-server-ip:8080"

  4. Verify Installation

    Get-Service ParentalControlClient

    Status should be "Running"

Client Configuration

The client configuration file is located at:

  • Linux: /opt/parental-control/appsettings.json
  • Windows: C:\Program Files\ParentalControl\appsettings.json
{
  "ParentalControl": {
    "ServerUrl": "http://your-server-ip:8080",
    "TickIntervalSeconds": 60
  }
}
Setting Description Default
ServerUrl URL of the central server http://localhost:8080
TickIntervalSeconds How often to check with server (in seconds) 60
⚠️ After changing configuration:
  • Linux: sudo systemctl restart parental-control-client
  • Windows: Restart-Service ParentalControlClient

How the Client Works

Verifying Client Status

Linux

# Check service status
sudo systemctl status parental-control-client

# View logs
sudo journalctl -u parental-control-client -f

# Check if running
ps aux | grep ParentalControl

Windows

# Check service status
Get-Service ParentalControlClient

# View logs
Get-Content "C:\ProgramData\ParentalControl\Logs\client-*.log" -Tail 50

# Check if running
Get-Process | Where-Object {$_.Name -like "*ParentalControl*"}

Tray Menu Options

Linux Tray (Avalonia UI)

The Linux client uses Avalonia UI for the system tray icon. It appears in the system tray of most desktop environments:

  • GNOME (with AppIndicator extension)
  • KDE Plasma
  • XFCE
  • Cinnamon
  • MATE
💡 GNOME Users: Install the AppIndicator extension for tray icon support: 
sudo apt install gnome-shell-extension-appindicator

Windows Tray (WPF UI)

The Windows client uses WPF for the system tray icon. It appears in the Windows system tray (bottom-right corner).

💡 Tip: If you don't see the icon, click the "^" arrow in the system tray to show hidden icons.

📝 Usage Scenarios

Scenario 1: Basic Time Limits

Goal: Limit child to 2 hours per day on weekdays, 3 hours on weekends

  1. Create User

    Go to Users → Add User

    • Username: sarah
    • Account Type: Child

  2. Create Time Profile

    Go to Time Profiles → Add Profile

    • User: sarah
    • Monday-Friday: 120 minutes
    • Saturday-Sunday: 180 minutes

  3. Install Client

    Install client on child's computer(s)

  4. Done!

    Sarah can now use the computer for 2 hours on weekdays and 3 hours on weekends

Scenario 2: Homework Hours Only

Goal: Allow computer use only during homework time (3 PM - 8 PM)

  1. Create User

    Username: alex, Account Type: Child

  2. Set Allowed Hours

    Go to Allowed Hours → Add Schedule

    Create schedules for Monday through Friday:

    • User: alex
    • Day: Monday
    • Start: 15:00
    • End: 20:00

    Repeat for Tuesday through Friday

  3. Optional: Add Time Limit

    Create time profile with 180 minutes daily limit

💡 Result: Alex can only log in between 3 PM and 8 PM on weekdays. Any login attempt outside these hours will be immediately terminated.

Scenario 3: Multiple Devices, Shared Time

Goal: Child has laptop and desktop, time limit applies to both

How it works:

  • Child uses laptop for 30 minutes → Server records 30 minutes used
  • Child switches to desktop → Server reports 75 minutes remaining (120 - 30 - 15)
  • Total time across both devices: 120 minutes per day

Scenario 4: Emergency Time Grant

Goal: Child needs extra time for school project

  1. Open Dashboard

    Navigate to Users page

  2. Click Time Button

    Click the ⏱️ Time button next to the user

  3. Grant Extra Time

    Choose from quick options:

    • +5 minutes
    • +15 minutes
    • +30 minutes
    • +60 minutes

  4. Time Added

    Extra time is added immediately and applies only to today

⚠️ Note: Emergency time grants are for TODAY ONLY. Tomorrow's limit resets to normal.

Scenario 5: Parent Account (Unlimited)

Goal: Parent needs unrestricted access

  1. Create User

    Username: mom, Account Type: Parent

  2. No Time Profile Needed

    Parent accounts have unlimited access by default

  3. Done!

    Mom can use the computer without any time restrictions

Scenario 6: Username Aliases

Goal: Child has multiple usernames (john, John, johnny) - treat as same user

  1. Primary User Exists

    User john already exists with time limits

  2. Child Logs In as "John"

    System auto-creates user John (capital J)

  3. Link Accounts

    Go to Users → Click 👥 Aliases next to john

    Select John from dropdown → Click Add Alias

  4. Done!

    Now John shares the same time limits as john

💡 Tip: Aliases are useful when:
  • Different capitalization (john vs John)
  • Nicknames (johnny, john)
  • Different computers use different username formats

🔧 Troubleshooting

Server Issues

Problem: Cannot access dashboard

Solutions:

  1. Check if containers are running: 
    docker ps
    You should see webservice and postgres
  2. Check logs: 
    docker logs webservice
  3. Verify port 8080 is not blocked: 
    curl http://localhost:8080
  4. Restart containers: 
    docker-compose restart

Problem: Database connection errors

Solutions:

  1. Check PostgreSQL container: 
    docker logs postgres
  2. Verify database password matches in docker-compose.yml
  3. Restart both containers: 
    docker-compose down
docker-compose up -d

Client Issues

Problem: Client not connecting to server

Solutions:

Linux:

# Test connection
curl http://your-server-ip:8080

# Check configuration
cat /opt/parental-control/appsettings.json

# Restart service
sudo systemctl restart parental-control-client

# View logs
sudo journalctl -u parental-control-client -n 50

Windows:

# Test connection
Invoke-WebRequest http://your-server-ip:8080

# Check configuration
Get-Content "C:\Program Files\ParentalControl\appsettings.json"

# Restart service
Restart-Service ParentalControlClient

# View logs
Get-Content "C:\ProgramData\ParentalControl\Logs\client-*.log" -Tail 50

Problem: Tray icon not showing

Linux Solutions:

  • GNOME: Install AppIndicator extension 
    sudo apt install gnome-shell-extension-appindicator
  • KDE: Enable system tray in panel settings
  • Check if UI process is running: 
    ps aux | grep ParentalControl.Client.UI

Windows Solutions:

  • Click "^" arrow in system tray to show hidden icons
  • Check if UI process is running: 
    Get-Process | Where-Object {$_.Name -like "*ParentalControl*"}

Problem: User not being logged out when time expires

Solutions:

  1. Verify time profile is active in dashboard
  2. Check client is reporting usage:
    • Go to Devices in dashboard
    • Verify "Last Seen" is recent (within 1 minute)
  3. Check client logs for enforcement errors
  4. Verify user account type is "Child" (not "Parent")

Common Issues

Issue Cause Solution
Time not syncing across devices Clients not connecting to same server Verify ServerUrl is identical on all clients
User has unlimited time Account type is "Parent" or "Unassigned" Change account type to "Child"
Dashboard shows wrong language Browser language detection Use language selector in top-right corner
Cannot edit in dashboard Read-only mode (not authenticated) Click "🔒 Unlock" and enter admin password
Multiple users for same person Different username capitalization Use Aliases feature to link accounts
